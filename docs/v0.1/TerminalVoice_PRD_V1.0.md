# TerminalVoice 产品需求文档（PRD）V1.1

**仓库名**：`TerminalVoice`
**产品定位**：Windows 平台后台常驻全局语音输入桌面工具
**适用场景**：终端 CLI、代码编辑器、AI Agent 命令行工具、普通桌面输入框等全场景文本输入
**文档版本**：V1.1
**更新日期**：2026-08-09

---

## 一、项目概述

### 1.1 项目背景
开发者在使用 Claude Code、CodeX 等 CLI 版 AI 工具时，常需要通过键盘逐字输入较长的自然语言问题、代码修改要求、上下文说明与操作指令。纯键盘输入效率低，容易打断开发思路；系统自带语音输入能力又缺少面向开发场景的快捷触发、预览编辑、历史管理、文本清洗和全局上屏能力。

### 1.2 产品目标
打造一款轻量、后台常驻的 Windows 桌面工具，不侵入原有软件、不自动执行命令、不改变用户「输入 → 编辑 → 确认发送」的操作习惯。用户通过全局快捷键触发录音，工具完成云端语音识别、文本预处理、预览编辑，并在用户确认后将文本填充到目标输入位置，替代长文本手动输入。

### 1.3 目标用户
- 高频使用 CLI 工具、命令行 AI Agent、代码编辑器的开发者
- 需要在任意桌面软件中快速输入长文本的办公用户
- 对输入内容准确性、可编辑性、隐私边界有明确要求的专业用户

### 1.4 核心价值
- **全局可用**：尽可能适配 Windows 中常见可输入控件，光标在哪，文本就填充到哪
- **流程可控**：先预览编辑，再确认上屏，避免识别错误直接进入目标软件
- **开发友好**：支持过滤口语词、单行规整、多种文本模式，减少命令和代码片段被错误改写
- **后台常驻**：托盘驻留，全局快捷键触发，不打断当前工作流
- **本地可控**：配置、历史、过滤词和日志保存在本机；音频仅在用户触发识别时发送至所选 ASR 服务商

### 1.5 V1.1 优化重点
- 明确云端 ASR 与本地隐私的边界，避免"完全不上传"与"云端识别"表述冲突
- 明确预览框焦点、目标输入位置和上屏填充的可实现规则
- 补充状态机、默认配置、异常矩阵和验收标准，降低开发与测试歧义
- 补充 Windows 全局输入兼容性限制和降级策略

## 四、录音触发与控制模块

### 4.1 触发方式
- 采用**长按快捷键触发**机制：按住快捷键时开始录音，松开按键时自动结束录音并立即发起语音识别请求
- 若按住时间不足最短有效录音时长（0.5 秒），视为无效触发：不发起识别、不保留音频、不弹提示
- 快捷键在设置页自定义，修改时检测与其他全局快捷键和系统保留组合键（如 `Ctrl+Alt+Del`）的冲突并提示

### 4.2 取消机制
- 录音过程中按下 `ESC` 键，立即终止本次录音：不发起识别请求、不生成任何文本、清理临时音频文件
- 取消后工具回到空闲状态，不弹出任何提示

### 4.3 时长限制
- 单段录音最长默认为 60 秒，可在设置页自定义（范围 10-300 秒）
- 达到时长上限后**静默自动结束录音并进入识别流程**：即使用户仍按住快捷键也结束录音；不弹额外提示，与松开快捷键结束行为一致

### 4.4 全局开关
- 支持一键暂停/启用整个工具的语音输入功能
- 暂停状态下：
  - 按下录音快捷键完全无反应、无任何提示
  - 托盘图标切换为暂停态图标
  - 主界面状态标识同步更新
  - 其他功能（托盘菜单、设置页、历史记录查看）仍可用
- 重新启用后恢复正常，无需重新配置

### 4.5 录音中断场景
| 场景 | 行为 |
| :--- | :--- |
| 录音中麦克风设备被拔出或切换 | 立即终止录音，不发起识别，托盘提示"麦克风设备异常" |
| 录音中被其他应用独占麦克风 | 立即终止录音，不发起识别，托盘提示"麦克风被其他应用占用" |
| 录音中用户触发暂停 | 立即终止录音，不发起识别，回到暂停态 |
| 录音中用户退出应用 | 弹出确认对话框"正在录音中，确认退出？"；确认后终止录音，清理音频后退出 |

## 五、语音识别与文本预处理模块

### 5.1 识别方案
- 统一调用**云端第三方 ASR API**，不部署本地离线模型
- 采用**整段录音结束后一次性返回识别结果**的模式，不做流式实时识别
- 支持多家 ASR 服务商，用户在设置页选择并配置对应 API 密钥
- V1.1 至少集成 1 家服务商（如 阿里云/腾讯云/讯飞/百度/Whisper API），后续通过版本更新增加

### 5.2 音频规则
- 录音中间格式：16KHz、16-bit、单声道 PCM
- 最终编码由 ASR 服务商要求决定（如 WAV、PCM、Opus），工具在发送前做格式转换
- 识别完成后（无论成功或失败），临时音频文件立即删除，不本地留存
- 用户触发取消（ESC）时，已录制的音频同样立即删除

### 5.3 文本预处理规则
识别结果返回后，按以下顺序执行预处理：

**第一步：标点处理**（可关闭）
- 自动添加标准中文标点符号（，。！？；：）
- 仅在"普通文本模式"下生效；开发者模式和原样模式不添加

**第二步：口语词过滤**（可关闭）
- 默认过滤词库：嗯、啊、呃、哦、那个、这个、就是、然后、反正、就是说
- 过滤时按词边界匹配，不误删正常文本中的相同字符串
- 用户可在设置页新增、删除自定义过滤词，也可一键恢复默认词库

**第三步：单行规整**（可关闭）
- 去除文本中所有换行符（`\n`、`\r\n`）
- 合并连续多余空格为单个空格
- 去除首尾空白字符

**第四步：格式化输出**
- 预处理结果为初始初稿，送入预览编辑框供用户修改
- 最终上屏内容以用户在预览框中确认的内容为准

### 5.4 文本模式（V1.1 新增）
用户可在设置页选择文本处理模式：

| 模式 | 标点 | 过滤词 | 单行规整 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **普通文本模式**（默认） | 自动添加 | 启用过滤 | 单行规整 | 自然语言提问、邮件、文档 |
| **开发者模式** | 不添加标点 | 保留常见口语词 | 单行规整 | CLI 指令、代码注释、技术描述 |
| **原样模式** | 不添加 | 不过滤 | 不规整 | 保留识别原始输出，用户自行编辑 |

## 六、预览编辑与文本上屏模块

### 6.1 目标输入控件的捕获与恢复
这是 V1.1 最重要的实现细节变更，解决"预览框可编辑"与"上屏到目标位置"的焦点冲突：

1. **目标输入控件捕获**：在录音触发瞬间（按下快捷键时），记录当前获得焦点的可输入控件句柄及其窗口信息，作为"初始目标输入位置"
2. **预览框弹出**：识别完成后弹出预览编辑框，此时焦点转移到预览框内，用户自由编辑内容
3. **目标位置重定位**：用户确认上屏前，允许手动点击目标窗口重新定位光标；预览框保持可见且不抢回焦点
4. **确认上屏时**：
   - 第一步：隐藏预览框
   - 第二步：激活目标窗口，恢复其输入控件焦点
   - 第三步：将最终文本注入到目标输入控件当前光标位置
   - 第四步：保持目标输入控件聚焦，光标位于插入文本末尾
5. **目标窗口已关闭的兜底**：若确认上屏时原始目标窗口已不存在，尝试注入到当前系统焦点输入控件；若均无有效可输入控件，托盘提示"未检测到有效输入位置"，文本不丢失（保留在剪贴板中且预览框内容仍在内存中，用户可手动粘贴或重新上屏）

### 6.2 预览框弹出规则
- 识别成功后自动弹出预览编辑框，默认出现在**初始目标输入控件的光标附近**位置
- 若触发录音时无聚焦输入控件（如桌面、无输入框界面），预览框在屏幕中央弹出，用户需先定位光标再确认上屏
- 预览框为置顶窗口（Topmost），但在用户点击其他窗口时不强制获取焦点

### 6.3 预览框交互
- 预览框内为可编辑文本框，支持自由增删改内容
- 快捷键：
  - `Enter`：确认上屏（仅当预览框有焦点时生效，不会传递到目标应用）
  - `Ctrl+Enter`：在预览框内换行
  - `ESC`：关闭预览框，放弃本次输入，不上屏任何内容，不保存历史
- 提供可视化「确认上屏」按钮，与 Enter 键功能一致；提供「复制到剪贴板」按钮作为备选
- 预览框关闭（ESC）后，工具回到空闲状态

### 6.4 上屏填充规则
1. **内容规则**：
   - 光标无选中文本：在光标当前位置插入最终文本
   - 光标有选中内容：用最终文本替换选中的内容
2. **后置状态**：填充完成后自动保持目标输入控件聚焦，光标停在插入文本的末尾
3. **填充方式**：优先使用剪贴板粘贴（`Ctrl+V` 模拟），失败时回退到 `SendInput` / UI Automation 逐字符输入

### 6.5 上屏失败兜底
| 失败原因 | 兜底行为 |
| :--- | :--- |
| 目标输入控件为只读 / 密码框 | 不注入文本，托盘提示"目标位置不支持输入" |
| 目标窗口为管理员权限且工具无权限 | 不注入文本，托盘提示"目标窗口权限不足，请以管理员身份运行工具" |
| 模拟输入被安全软件拦截 | 将文本复制到系统剪贴板，托盘提示"输入被拦截，文本已复制到剪贴板" |
| 目标输入控件无法通过程序化方式注入 | 降级为剪贴板方案，托盘中提示用户手动粘贴 |

### 6.6 预览框异常关闭
- 若预览框因崩溃、系统关机等异常关闭而未完成确认或取消，不执行上屏，文本不保存到历史

## 七、状态与反馈模块

### 7.1 状态机流程图

```
                    ┌──────────┐
         启动 / 启用  │   空闲    │
        ┌───────────│  (Idle)   │◄──────────────┐
        │           └─────┬─────┘                │
        │                 │ 按下快捷键              │
        │                 ▼                      │
        │           ┌──────────┐    ESC / 异常     │
        │           │  录音中   │──────────────┐   │
        │           │(Recording)│              │   │
        │           └─────┬─────┘              │   │
        │    松开快捷键 / 到上限  │                 │   │
        │                 ▼                      │   │
        │           ┌──────────┐    失败+重试耗尽  │   │
        │           │  识别中   │──────────────┐   │
        │           │(Recognizing)│            │   │
        │           └─────┬─────┘              │   │
        │         识别成功  │                   │   │
        │                 ▼                      │   │
        │           ┌──────────┐     ESC        │   │
        │           │  预览中   │──────────────┐   │
        │           │(Preview)  │              │   │
        │           └─────┬─────┘              │   │
        │         确认上屏  │                      │   │
        │                 ▼                      │   │
        │           ┌──────────┐                 │   │
        └──────────►│ 上屏完成  │                 │   │
                    │ (Done)    │─────────────────┘   │
                    └──────────┘                       │
                                                       │
              ┌──────────┐                             │
              │   暂停    │◄──── 用户触发暂停 ──────────┘
              │ (Paused)  │──── 用户启用 ──────► 空闲
              └──────────┘
```

### 7.2 各状态下事件响应矩阵

| 状态 | 按录音快捷键 | 按 ESC | 触发暂停 | 退出应用 |
| :--- | :--- | :--- | :--- | :--- |
| **空闲** | 进入录音中 | 无反应 | 进入暂停态 | 直接退出 |
| **录音中** | 无反应 | 取消录音，回空闲 | 终止录音，进暂停态 | 确认后终止录音并退出 |
| **识别中** | 无反应 | 取消请求，回空闲 | 暂停托盘通知仍显示，后台继续直至完成 | 确认后等待当前请求完成或超时后退出 |
| **预览中** | 无反应 | 关闭预览框，回空闲 | 关闭预览框，不保存，进暂停态 | 确认后关闭预览框并退出 |
| **暂停** | 无反应 | 无反应 | 恢复启用，回空闲 | 直接退出 |

### 7.3 录音中反馈
- 录音期间，在当前光标位置附近显示悬浮提示：「倾听中」文字 + 实时录音秒数（如 "倾听中 0:12"）
- 提示层不抢占输入焦点，不影响正常操作
- 支持在设置页关闭录音悬浮提示

### 7.4 识别中反馈
- 识别进行中时，悬浮提示切换为「识别中…」，时长超过 5 秒无返回时显示为「识别中…（较慢）」
- 识别完成自动消失

### 7.5 结果反馈
- **识别成功**：自动弹出预览编辑框，不额外弹成功提示
- **识别失败**：通过系统托盘气泡通知展示失败原因，定义以下错误类型和提示文案：

| 失败原因 | 托盘提示文案 |
| :--- | :--- |
| 网络不可达 / DNS 解析失败 | "网络连接失败，请检查网络" |
| 连接超时 | "语音识别连接超时，请稍后重试" |
| API 密钥无效（401/403） | "API 密钥无效，请在设置中检查配置" |
| 调用额度不足（429/402） | "API 调用额度不足，请联系服务商" |
| 服务端错误（5xx） | "语音服务暂时不可用，请稍后重试" |
| 无有效音频（过短 / 无声音） | "未检测到有效语音" |
| 麦克风权限未开启 | "麦克风权限未开启，请在系统设置中授权" |
| 音频文件损坏 / 格式异常 | "音频处理异常，请重试" |

### 7.6 工具状态标识
- 系统托盘图标区分「运行中」与「已暂停」两种状态：运行中为彩色图标，暂停为灰色图标
- 主界面顶部栏同步展示当前工具状态和文字说明

## 九、主界面与设置模块

### 9.1 主界面基础规则
- 独立桌面客户端窗口（以独立窗口形态运行，非浏览器中打开网页；技术层面可使用系统 WebView 作为渲染引擎，但用户感知为独立桌面应用）
- 窗口支持最小化、关闭（关闭行为由设置决定：默认退至托盘）
- 界面包含两个核心标签页：历史记录、设置
- 窗口标题栏显示工具名称和当前运行状态

### 9.2 历史记录页

**存储字段：**

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| id | INTEGER PK | 自增主键 |
| created_at | TEXT | 记录创建时间（ISO 8601） |
| source_text | TEXT | 原始识别文本（API 返回 + 预处理后的内容） |
| final_text | TEXT | 最终上屏文本（用户在预览框编辑后确认的内容） |
| text_mode | TEXT | 当时使用的文本模式 |
| asr_provider | TEXT | 当时使用的 ASR 服务商 |

**支持操作：**
- 按时间倒序列表展示，每条显示创建时间和最终文本的前 50 个字符预览
- 点击展开查看完整原始文本和最终文本
- 一键复制最终文本到剪贴板
- 一键重新上屏：将该条最终文本填充到当前系统光标位置（无预览，直接上屏；失败则提示）
- 删除单条记录（确认后物理删除，不可恢复）
- 清空全部历史（需二次确认）
- 支持按关键词搜索历史记录

**历史记录写入规则：**
- 用户确认上屏成功：写入一条完整记录（source_text + final_text）
- 用户 ESC 取消预览：不写入历史
- 上屏失败：仍然写入历史（标记 final_text，但记录写入与否不依赖上屏成败）

### 9.3 设置页

**1. ASR 配置：**
- ASR 服务商下拉选择（显示已集成的服务商列表）
- API 密钥输入框（密文显示，使用 Windows DPAPI 加密存储）
- 自定义接口地址（如服务商支持私有部署或代理）
- 「测试连接」按钮：发送一段短音频测试请求，返回成功/失败及耗时

**2. 录音配置：**
- 最长录音时长滑块（10-300 秒，步长 10 秒，默认 60）
- 麦克风设备下拉选择（列出系统可用录音设备）
- 「测试录音」按钮：录制 3 秒音频并播放回放，验证设备和音量

**3. 文本配置：**
- 文本模式选择：普通文本 / 开发者 / 原样
- 自动添加标点开关（仅普通文本模式生效）
- 单行规整开关
- 口语词过滤开关 + 自定义过滤词管理（列表展示、新增、删除、一键恢复默认）

**4. 快捷键配置：**
- 录音触发快捷键录制框（点击后按下目标快捷键自动捕获）
- 冲突检测：与已知系统保留组合键和全局热键对比，冲突时红色提示并阻止保存
- 重置为默认快捷键

**5. 通用设置：**
- 开机自启开关
- 关闭窗口时最小化到托盘 / 直接退出
- 录音悬浮提示开关
- 历史记录自动清理：上限条数设置

## 十、数据存储模块

### 10.1 存储方案
- 全部本地结构化数据采用 **SQLite** 数据库，存放于用户工作目录下的 `data/` 子目录
- 数据库文件支持通过托盘菜单快速打开
- 首次启动时自动创建数据库和表结构，后续版本升级时执行迁移脚本

### 10.2 存储内容
1. **系统配置表（config）**：所有设置页参数以 key-value 形式持久化
2. **历史记录表（history）**：见 9.2 字段定义
3. **自定义过滤词表（filter_words）**：过滤词文本、是否默认词、创建时间
4. **程序运行日志**：独立日志文件，存储于 `logs/` 目录，不写入数据库

### 10.3 数据库损坏恢复
- 启动时检测 SQLite 完整性（`PRAGMA integrity_check`）
- 若检测到损坏：备份损坏文件（追加 `.bak` 后缀），创建新数据库，配置恢复默认值，历史记录丢失但托盘通知用户
- 日志文件损坏不影响程序启动，仅丢弃损坏日志

### 10.4 数据清理
- 历史记录超出上限时，按创建时间升序删除最旧记录（保留最新 N 条）
- 日志文件按保留天数清理，超期日志物理删除
- 提供「清除所有本地数据」按钮（设置页底部），需二次确认，清除后自动恢复默认配置

## 十一、非功能需求

### 11.1 性能要求
- 录音结束到识别结果返回，客户端处理耗时 ≤ 0.5 秒；网络传输 + ASR 服务端处理耗时取决于网络和服务商，正常短句（≤ 10 字）场景 P90 ≤ 3 秒
- 后台常驻内存占用 ≤ 100MB（不含操作系统缓存），CPU 空闲时占用 < 1%
- 程序冷启动时间 ≤ 2 秒（不含首次数据库创建）
- 录音过程不导致系统或目标应用出现可感知的卡顿

### 11.2 稳定性要求
- 后台长期常驻运行，无内存泄漏（运行 24 小时后内存增量 ≤ 10MB）
- API 调用失败自动重试 1 次，重试失败再提示错误
- 异常退出后，重启可自动恢复原有配置
- Explorer 重启后托盘图标自动恢复

### 11.3 兼容性要求
- 支持 Windows 10（21H2+）及以上版本，Windows 11 全版本
- **已知兼容性限制（V1.1 不保证完美支持）：**
  - 管理员权限窗口：工具需以管理员身份运行才能注入文本
  - UAC 安全桌面 / 登录屏幕：不支持
  - 部分游戏全屏模式 / DirectX 独占全屏：可能无法正常捕获光标位置
  - 远程桌面会话：取决于 RDP 协议对剪贴板和输入模拟的支持
  - 部分基于 Electron 且使用自定义输入法的应用：可能需降级为剪贴板方案
- 兼容主流终端工具（Windows Terminal、CMD、PowerShell、WSL、Git Bash）
- 兼容主流代码编辑器（VS Code、JetBrains 系列、Cursor、Notepad++ 等）
- 兼容 Claude Code、CodeX 等 CLI AI Agent 工具

### 11.4 隐私与安全
- **音频**：录制音频仅用于当次识别请求，发送至用户选择的 ASR 服务商；识别完成后（成功或失败）立即从本地删除，不留存
- **用户数据**：配置、历史记录、过滤词、日志等所有本地数据不上传任何第三方服务器
- **API 密钥**：使用 Windows DPAPI（Data Protection API）加密存储，仅在发起 ASR 请求时解密使用
- **日志**：不得记录 API Key 明文、完整音频内容、完整识别文本（可记录文本长度和首尾字符用于排查）
- **崩溃报告**：如包含崩溃转储，不得包含密钥、音频和识别文本
- **网络请求**：除用户配置的 ASR API 调用外，工具不发起任何其他网络请求（含遥测、版本检查等）

### 11.5 安装与更新
- V1.1 提供 Windows 安装包（MSI 或 NSIS 安装器），支持自定义安装路径
- 提供卸载入口（控制面板 / 安装目录下 Uninstall.exe），卸载时清理注册表、托盘、启动项，保留用户数据目录需用户确认
- 版本更新策略（V1.1 不做自动更新，后续版本补充）

## 十二、边界与异常处理完整矩阵

### 12.1 录音阶段
| 场景 | 行为 | 用户可见提示 |
| :--- | :--- | :--- |
| 首次启动未授权麦克风 | 进入空闲状态，功能不可用 | 托盘气泡："麦克风权限未开启，请在系统设置中授权" |
| 录音快捷键被系统/其他应用抢占 | 录音无法触发 | 在设置页显示冲突警告，引导用户更换 |
| 按住时间 < 0.5 秒 | 不发起识别，丢弃音频 | 无提示（静默丢弃） |
| 录音中系统进入休眠/睡眠 | 终止录音，丢弃音频 | 唤醒后托盘图标恢复，无额外通知 |
| 当前无默认录音设备 | 录音无法启动 | 托盘气泡："未检测到可用麦克风设备" |

### 12.2 识别阶段
| 场景 | 行为 | 用户可见提示 |
| :--- | :--- | :--- |
| 网络断开 | 重试 1 次，仍失败则终止识别 | 托盘气泡："网络连接失败，请检查网络" |
| 连接超时（超时时间内无响应） | 重试 1 次，仍超时则终止 | 托盘气泡："语音识别连接超时，请稍后重试" |
| API 返回空文本 | 进入预览框（显示空文本），用户可手动输入 | 预览框弹出自带提示"识别结果为空" |
| 识别中用户切换到暂停 | 后台继续完成当前识别 | 识别完成后不弹预览框，静默丢弃（暂停态不弹出任何UI） |
| 识别中用户退出应用 | 确认后等待请求完成或超时 | 确认对话框："有正在进行的语音识别，确认退出？" |

### 12.3 预览阶段
| 场景 | 行为 | 用户可见提示 |
| :--- | :--- | :--- |
| 目标输入控件所属窗口在预览期间被关闭 | 上屏时尝试注入当前焦点控件 | 兜底失败则提示"未检测到有效输入位置" |
| 预览框中用户清空所有内容后确认 | 上屏空内容（即删除光标处选中文本或插入空串） | 正常行为，无额外提示 |
| 预览框弹出时多显示器 / DPI 缩放不一致 | 预览框显示在正确的屏幕和缩放比例下 | 无（程序自行处理 DPI 感知） |

### 12.4 上屏阶段
| 场景 | 行为 | 用户可见提示 |
| :--- | :--- | :--- |
| 目标输入控件为只读 | 不注入文本 | 托盘气泡："目标位置不支持输入" |
| 目标窗口为管理员权限，工具未以管理员运行 | 不注入文本 | 托盘气泡："目标窗口权限不足，请以管理员身份运行工具" |
| 模拟输入被安全软件拦截 | 降级为剪贴板方案 | 托盘气泡："输入被拦截，文本已复制到剪贴板" |
| 目标控件不支持程序化注入（如某些终端自定义输入） | 降级为剪贴板方案 | 如果剪贴板方案也失败，提示"无法注入文本，请手动粘贴"（文本已在剪贴板） |

### 12.5 程序生命周期
| 场景 | 行为 | 用户可见提示 |
| :--- | :--- | :--- |
| 程序多开（重复运行 exe） | 检测已有实例，唤起其主窗口 | 已运行实例主窗口置顶显示 |
| 系统关机 / 注销 | 终止所有进行中的操作，清理临时文件后退出 | 无（系统级通知已覆盖） |
| 托盘图标因 Explorer 重启丢失 | 自动重新注册托盘图标 | 无（静默恢复） |
| 数据库文件损坏 | 备份 → 重建 → 恢复默认配置 | 托盘气泡："数据库已重置，历史记录可能丢失" |

## 十三、功能边界（V1.1 不做）

1. 不做本地离线语音识别模型，全部依赖云端 ASR API
2. 不做实时流式识别，仅支持整段录音结束后一次性返回
3. 不做 AI 对话、命令执行、自动提交，仅负责语音转文字并填充到目标输入位置
4. 不做声纹识别、多人说话区分
5. 不做长时会议转录、实时字幕功能
6. 不做语音翻译功能，仅支持同语言语音转文字
7. V1.1 仅支持 Windows 平台，不覆盖 macOS、Linux
8. 不做鼠标控制、窗口管理等超出文本输入的操作
9. 不做自动更新功能，版本更新由用户手动下载安装
10. 不做多语言 UI 国际化，V1.1 仅支持简体中文界面

```
            │       │
            │       ├─ 用户编辑 → Enter/确认按钮 → 上屏 → 保存历史 → 回空闲
            │       └─ ESC → 放弃 → 回空闲
            │
            └─ 失败 → 重试1次
                    ├─ 成功 → 同上
                    └─ 失败 → 托盘提示 → 回空闲
```

## 十六、技术选型

### 16.1 技术栈总览（2026-08 更新）

| 层 | 选型 | 版本 | 说明 |
| :--- | :--- | :--- | :--- |
| **后端核心** | Rust | ≥ 1.85 (stable) | 性能关键路径：录音、ASR 调用、文本注入、全局热键 |
| **桌面框架** | Tauri v2 | ≥ 2.5 | Rust 后端 + 系统 WebView2 渲染前端；打包为独立桌面窗口 |
| **Tauri 插件** | global-shortcut / clipboard-manager / dialog / shell / autostart | 2.x | 全局热键、剪贴板、对话框、自启等官方插件 |
| **前端 UI** | React + TypeScript | React 19 / TS 5.7+ | 设置页、历史记录页、预览弹窗 |
| **构建工具** | Vite + @vitejs/plugin-react | Vite 8 / plugin-react 6 | 基于 Rolldown + Oxc，构建速度较 Vite 5 提升数倍 |
| **CSS / UI 组件** | Tailwind CSS v4 + shadcn/ui (CLI v4) | Tailwind 4.3+ | Oxide 引擎、CSS 优先配置 (`@import "tailwindcss"`)；组件按需拷贝 |
| **状态管理** | Zustand | 5.x | 轻量前端状态管理 |
| **音频** | cpal + hound | cpal 0.18 / hound 3.5 | Rust 跨平台音频库；0.18 新增 Linux PipeWire/PulseAudio 原生后端 |
| **HTTP** | reqwest + tokio | reqwest 0.12 / tokio 1.x | Rust 异步 HTTP，调用 ASR API |
| **数据库** | SQLite (rusqlite, bundled) | rusqlite 0.40 | 配置、历史记录、过滤词本地存储 |
| **加密** | Windows DPAPI (windows-sys crate) | windows-sys 0.61 | API 密钥本地加密存储 |
| **文本注入** | enigo + arboard | enigo 0.6 / arboard 3 | 剪贴板 Ctrl+V 优先 → enigo Unicode 注入降级；enigo 内部封装 SendInput |
| **日志** | tracing + tracing-subscriber + tracing-appender | tracing 0.1 / subscriber 0.3 | 结构化日志，滚动文件输出 |
| **打包** | Tauri 内置 NSIS 3.11（主） + WiX v3（MSI，可选） | — | `tauri build` 首次构建时自动下载，**无需手动安装 WiX** |

### 16.2 选型理由

- **Tauri v2**：用系统 WebView2 渲染 UI，Rust 处理所有核心逻辑（录音/ASR/注入/热键）。用户感知为独立桌面窗口，非浏览器打开；二进制体积小（~10-15MB），内存低（~50-70MB），远低于 PRD 100MB 上限。
- **Rust 后端**：全局热键由 `tauri-plugin-global-shortcut`（底层 `global-hotkey` 0.8+）原生提供 press/release 事件，无需 `GetAsyncKeyState` 轮询；音频/文本注入通过 cpal 0.18 与 enigo 0.6 trait-based API 完成；cpal/reqwest/rusqlite 生态成熟。
- **TypeScript 前端**：React 19 + Tailwind v4 + shadcn/ui 开发效率高，组件生态丰富；Vite 8 的 Rolldown 引擎显著提升构建速度；TS 路径别名由 Vite 内置解析，无需额外插件。

### 16.3 开发环境要求

| 工具 | 最低版本 | 用途 |
| :--- | :--- | :--- |
| Rust | 1.85+ (stable) | 后端编译（cpal 0.18 要求 MSRV 1.85） |
| Node.js | **22 LTS** (Jod) | 前端构建（Node 20 LTS 已于 2026-04 结束维护） |
| pnpm | 10+（推荐最新） | 包管理（统一使用 pnpm，避免 npm 混用） |
| Visual Studio Build Tools | 2022（含"C++ 桌面开发"与 Win10/11 SDK） | Tauri/CPAL/ENIGO 编译依赖 |
| WebView2 Runtime | 系统自带（Win10 2004+ / Win11） | Tauri 渲染引擎；精简系统可通过 Bootstrapper 自动安装 |

> **不需要手动安装**：WiX Toolset、NSIS。首次执行 `pnpm tauri build` 时，Tauri 会自动下载 NSIS 3.11 与 WiX v3 工具链到缓存目录。
