# AGENTS.md — src-tauri（Rust 后端）

## 定位

TerminalVoice 的 **Tauri v2 后端**，承担：SQLite 持久化、全局热键监听、麦克风录音、语音管线编排、文本注入，以及向前端暴露 IPC 命令与推送事件。前端通过 `invoke` 命令调用，通过 `emit` 事件接收状态变化。

## 技术栈

- Rust 1.85+（edition 2021），crate 名 `terminalvoice`，lib 名 `terminalvoice_lib`
- 核心依赖（见 [Cargo.toml](Cargo.toml)）：`tauri 2`、`rusqlite 0.40`（bundled + WAL）、`cpal 0.16`（录音）、`rdev`（热键）、`enigo` + `arboard`（注入）、`rubato`（重采样）、`hound`（WAV）

## 目录结构

```
src-tauri/
```
