# AGENTS.md — src（Rust 源码根）

## 定位

`terminalvoice_lib` crate 的源码根，由 [lib.rs](lib.rs) 的 `run()` 完成装配，是后端逻辑的唯一入口。

## 文件清单

| 文件 | 职责 |
| :--- | :--- |
| [main.rs](main.rs) | 进程入口，仅调用 `terminalvoice_lib::run()` |
| [lib.rs](lib.rs) | Tauri Builder：setup（建数据目录 → 打开 DB → `manage` 状态 → 启动热键管线）+ 注册 8 个 invoke handler |
| [state.rs](state.rs) | 运行时状态机（5 状态 + 8 事件 + 7 单元测试） |
| [commands/](commands/) | IPC 命令层（见 commands/AGENTS.md） |
| [services/](services/) | 业务服务层（见 services/AGENTS.md） |

## lib.rs 装配流程（`run()`）

1. 解析 `app_data_dir` 并 `create_dir_all`
2. 打开 `terminalvoice.db`（SQLite）
3. `app.manage(Mutex<Database>)` + `app.manage(Mutex<AppRuntime>)`
4. `services::pipeline::start_hotkey_pipeline(...)`
5. `tauri::generate_handler!` 注册 8 个命令后 `run()`

## 状态机（state.rs）

- **RuntimeState（5）**：`Idle` / `Recording` / `Recognizing` / `Preview` / `Paused`
- **RuntimeEvent（8）**：`HotkeyPressed` / `HotkeyReleasedWithValidAudio` / `HotkeyReleasedTooShort` / `RecognitionSucceeded` / `RecognitionFailed` / `ConfirmedPreview` / `Cancelled` / `TogglePause`
- 核心方法 `AppRuntime::transition(event) -> Result<RuntimeState, StateError>`；`Paused` 通过 `paused_from` 记录恢复源状态
- 详见 [../docs/STATE_MACHINE.md](../docs/STATE_MACHINE.md)

## 模块依赖方向

```text
main.rs  →  lib.rs  →  commands/  +  services/  +  state.rs
```

- `commands` 调用 `services`（向下依赖）
- `services::pipeline` 是编排中心，调用 `hotkey` / `recorder` / `preprocess` / `injector` / `db` / `events`
- **注意**：`services::events` 反向引用了 `commands::preview` 的类型（`AppStatus` / `RuntimeStateChangedPayload`），属跨层引用，改造分层时需留意该耦合点

## 命名与序列化约定

- 模块 / 文件 `snake_case`；命令函数用 `#[tauri::command]` 标注
- Rust struct 通过 `#[serde(rename_all = "camelCase")]` 或显式 `#[serde(rename = "...")]` 对齐前端 camelCase（`db.rs` 的 `HistoryItem` 未加 rename，当前 JSON 字段为 snake_case，属已知不一致）
- 错误统一返回 `Result<T, String>`，错误信息经 `to_string()` / `format!` 转为字符串
