# AGENTS.md — services（业务服务层）

## 定位

纯业务逻辑层，不直接暴露 IPC，由 [commands](../commands/AGENTS.md) 或 [../lib.rs](../lib.rs) / pipeline 调用。

## 模块清单

| 模块 | 职责 | 关键导出 |
| :--- | :--- | :--- |
| [db.rs](db.rs) | SQLite 三表（`config` / `history` / `filter_words`）+ WAL + 默认过滤词种子 | `Database` / `HistoryItem` / `NewHistoryItem` / `ConfigEntry` |
| [preprocess.rs](preprocess.rs) | 文本预处理（Normal / Developer / Raw 三模式 + 过滤词 + 标点） | `process_text` / `TextMode` / `PreprocessConfig` / `DEFAULT_FILTER_WORDS` |
| [recorder.rs](recorder.rs) | cpal 麦克风录音（跨采样格式 → 单声道 → 16k） | `Recorder` / `AudioBuffer` / `MIN_RECORDING_DURATION` / `MAX_RECORDING_DURATION` / `list_input_devices` |
| [audio.rs](audio.rs) | WAV 编码 + 16k 重采样 | `encode_wav` / `float_to_i16` / `resample_to_16k` / `TARGET_SAMPLE_RATE` |
| [hotkey.rs](hotkey.rs) | 全局热键（Right Alt = `Key::AltGr`，含边沿去抖） | `HotkeyEvent` / `HotkeyEdgeState` / `spawn_listener` |
| [events.rs](events.rs) | 事件推送封装（状态 + toast） | `emit_runtime_state` / `transition_runtime` / `emit_toast` / `ToastPayload` |
| [injector.rs](injector.rs) | 文本注入（enigo 优先，arboard 剪贴板 + Ctrl+V 兜底） | `inject_text` |
| [pipeline.rs](pipeline.rs) | 语音管线编排（热键 → 录音 → 预处理 → 注入 → 存历史） | `start_hotkey_pipeline` |

## 依赖方向

```text
pipeline → hotkey / recorder / preprocess / injector / db / events
events   → commands::preview（跨层引用其 AppStatus / RuntimeStateChangedPayload）
```

- 本层不依赖 `commands`（除 `events` 的上述跨层引用外）
- `pipeline.rs` 是唯一编排入口，其余模块相对独立、可单测

## 约定

- 错误统一 `Result<_, String>`；用户可见文案使用中文
- 常量集中定义（如 `TARGET_SAMPLE_RATE = 16_000`、`MIN_RECORDING_DURATION = 300ms`、`MAX_RECORDING_DURATION = 120s`、`DEFAULT_MOCK_ASR_TEXT`）
- 当前 ASR 未接入真实模型，`pipeline` 使用 `mock_asr_text` 配置项（缺省 `DEFAULT_MOCK_ASR_TEXT`）
