# AGENTS.md — commands（IPC 命令层）

## 定位

Tauri `invoke` 命令处理器，前端 [src/lib/commands.ts](../../lib/commands.ts) 的同名封装后端实现。命令统一在 [../lib.rs](../lib.rs) 的 `generate_handler!` 中注册。

## 文件与命令

| 文件 | 命令 | 说明 |
| :--- | :--- | :--- |
| [mod.rs](mod.rs) | — | 声明 `audio` / `config` / `history` / `preview` 四个子模块 |
| [config.rs](config.rs) | `get_config` / `set_config` / `list_config` | 配置 CRUD；`set_config` 成功后 `emit("config-updated")` |
| [history.rs](history.rs) | `list_history` | 历史列表（最新在前） |
| [preview.rs](preview.rs) | `get_app_status` / `create_mock_preview` / `confirm_preview` | 状态查询 / mock 预览 / 确认；推进状态机并 `emit("runtime-state-changed")` |
| [audio.rs](audio.rs) | `list_audio_input_devices` | 枚举录音输入设备 |

## 本层发出的事件

| 事件 | payload | 来源 |
| :--- | :--- | :--- |
| `runtime-state-changed` | `{ state: AppStatus }` | preview.rs |
| `config-updated` | `{ key, value }` | config.rs |

## 命令签名约定

- 每个命令返回 `Result<T, String>`，错误经 `.map_err(|e| e.to_string())` 转字符串
- 共享状态通过 `State<'_, Mutex<...>>` 注入（如 `Mutex<Database>`、`Mutex<AppRuntime>`）
- 需要推送事件的命令额外注入 `AppHandle` 并使用 `Emitter::emit`

## 本层类型定义

- [preview.rs](preview.rs)：`AppStatus`（镜像 `RuntimeState`）、`TextMode`、`PreviewDraft`、`ConfirmPreviewInput`、`RuntimeStateChangedPayload`
- [config.rs](config.rs)：`ConfigUpdatedPayload`
- [audio.rs](audio.rs)：`AudioInputDevice`
