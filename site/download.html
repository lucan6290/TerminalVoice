源码构建

从源码构建

开发者可从源码编译运行，体验最新功能。

bash 
# 克隆仓库
$ git clone https://github.com/lucan6290/TerminalVoice.git
$ cd TerminalVoice

# 安装依赖
$ pnpm install

# 开发模式（浏览器预览 UI）
$ pnpm dev

# Tauri 开发（前端 + Rust 后端）
$ pnpm tauri dev
